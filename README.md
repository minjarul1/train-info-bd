# Bangladesh Railway - Train Information Website

A clean, green-and-white designed train information website for Bangladesh Railway.

## Features

- ✅ **Live Departures Board** - Real-time train status
- ✅ **Search Functionality** - Find trains between stations
- ✅ **Status Indicators** - On time, Delayed, Cancelled, Platform changes
- ✅ **Mobile Responsive** - Works on all devices
- ✅ **Service Notices** - Current disruptions and alerts
- ✅ **Quick Links** - Booking, tracking, helpline

## Design System

Follows the green and white design guide:
- **Rail Green** `#0B5D3B` - Brand and navigation
- **Signal Green** `#11824A` - On-time status
- **Forest Ink** `#07281B` - Body text
- **Leaf** `#BFE3CD` - Borders and dividers
- **Mint** `#E3F4EA` - Highlights and hover states

## How to Use

1. Select **From** and **To** stations
2. Click **Find Trains**
3. View schedule, timing, and status
